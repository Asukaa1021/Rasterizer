# Rasterizer

**基于 QEM 网格简化的 C++ 软件光栅器与 OBJ 模型查看器。**

沿着 GAMES101 的学习思路，从向量和矩阵开始，手动实现三维变换、三角形光栅化、深度测试与基础光照，再扩展到 OBJ 模型导入、交互相机、网格简化和 LOD（细节层次）切换。几何处理和光栅化在 CPU 上完成，OpenCV 负责窗口、鼠标事件和图像显示。

当前默认显示黑底白色线框，可以拖动观察模型，并通过滚轮缩放查看不同距离下的三角网格细节。

## 功能与当前状态

| 模块 | 已实现内容 |
| --- | --- |
| 数学基础 | Vec2 / Vec3 / Vec4、点乘与叉乘、归一化、Mat4 矩阵运算、平移、旋转、缩放、lookAt 和透视投影。 |
| 模型导入 | 读取三角面 OBJ，保存顶点和面索引；通过包围盒计算统一的居中、等比例缩放变换。 |
| 软件光栅化 | MVP 变换、透视除法、屏幕映射、像素中心覆盖判断，以及基于重心坐标的插值和深度缓冲。 |
| 基础光照 | 实现环境光、平行光漫反射和 Blinn–Phong 高光。 |
| 线框显示 | 用 DDA 方法绘制三角形三条边，并根据世界空间法线与观察方向进行背面剔除。 |
| QEM 网格简化 | 累积平面误差矩阵，计算边折叠候选位置，使用优先队列选择候选，并局部更新邻接关系和候选边。 |
| 折叠检查 | 边界顶点保护、公共邻居检查、重复面检查，以及局部三角形退化和翻面检查。 |
| LOD 切换 | 启动时生成原始、目标约一半面数、目标约四分之一面数三档模型；根据相机距离选择，使用不同进出阈值减少来回切换。 |
| 交互相机 | 鼠标左键拖动绕目标旋转，滚轮调整相机距离，限制俯仰角和缩放范围。 |

**当前运行路径是线框渲染。**面填充、深度测试和光照代码保留在项目中，但填充部分目前在 `Rasterizer.cpp` 中被注释，尚未提供运行时模式切换按键。背面剔除依赖一致且朝外的面朝向，也不等同于完整的隐藏线消除：凹模型或互相遮挡的部件仍可能透出边线。

## 快速运行

### 开发环境

- Windows，支持 `.slnx` 和 v145 工具集的 Visual Studio。
- C++20。
- OpenCV 4.13.0。

### 构建

1. 打开 `Rasterizer.slnx`，选择 **Debug / x64**。
2. 根据自己的 OpenCV 安装位置修改项目属性：
   - **C/C++ → 常规 → 附加包含目录**：`<OpenCV>/build/include`
   - **链接器 → 常规 → 附加库目录**：`<OpenCV>/build/x64/vc16/lib`
   - **链接器 → 输入 → 附加依赖项**：`opencv_world4130d.lib`
3. 将对应的 `opencv_world4130d.dll` 放在可执行文件旁，或把 OpenCV 的 `bin` 目录加入运行时 `PATH`。
4. 生成并启动程序，在控制台输入 OBJ 文件路径，例如 `C:\Models\sphere.obj`，不加引号。
5. 等待两档简化模型生成。控制台会输出各档实际面数，然后进入交互显示。

工程当前的 Debug / x64 配置使用本机路径 `D:\OpenCV\opencv`，其他电脑需要修改。Release / x64 的 OpenCV 配置需另行补齐，并使用对应的不带 `d` 的库和 DLL。大模型的启动简化可能需要较长时间，窗口在进入事件循环前可能暂时无响应。

### 操作方式

| 操作 | 效果 |
| --- | --- |
| 按住鼠标左键拖动 | 绕模型旋转相机。 |
| 鼠标滚轮 | 拉近或拉远相机，距离变化时自动选择 LOD。 |
| 图片窗口获得焦点后按 Esc | 退出程序。 |

默认画布为 800 × 600。各档模型共用原始模型的居中与缩放矩阵，避免切换时重新计算包围盒导致显示位置或大小改变。LOD 是预先生成后离散切换，尚未实现连续几何变形。

## OBJ 输入要求

当前读取器支持：

- `v x y z` 顶点记录。
- 恰好含三个顶点的 `f` 面记录。
- 正整数位置索引，以及 `v/vt`、`v//vn`、`v/vt/vn` 形式的面编号；仅提取第一个斜杠前的位置索引。

顶点需要在引用它们的面之前出现。暂不支持负索引、四边形和多边形自动三角化；纹理坐标、导入法线和材质不参与当前绘制。建议使用朝向一致的有效三角网格，简化检查不构成对任意非流形输入的完整修复或验证。

| --- | --- |

| `raster_math.h` | 数学工具：定义向量和四阶矩阵，实现几何运算及模型、视图、投影变换。 |

| `mesh.h` | 索引网格结构：分别保存顶点位置数组和三角形索引数组，使多个面能够共享顶点。 |
| `obj_loader.h` | OBJ 文本读取：逐行解析顶点和三角面，提取带斜杠编号中的位置索引，并检查索引范围。 |
| `Rasterizer.h` | 光栅器接口：持有变换矩阵、画布尺寸、颜色及深度缓冲，声明清屏、三角形绘制和画线方法。 |
| `Rasterizer.cpp` | 像素生成：完成坐标变换、背面剔除和 DDA 画线，同时保留三角形填充、插值及深度测试实现。 |
| `shade.h` | 声明着色函数的输入和输出，连接光栅化得到的表面信息与光照计算。 |
| `shade.cpp` | 光照计算：根据法线、光照方向、表面位置和相机位置计算漫反射与高光颜色。 |
| `mesh_simplifier.h` | 简化算法的数据与接口：定义 Quadric、折叠候选、邻接与存活状态、版本号及优先队列。 |
| `mesh_simplifier.cpp` | 简化算法实现：求解候选位置、检查折叠合法性、维护局部邻接与候选队列，最后压紧顶点数组并重建面索引。 |
| `Rasterizer.slnx` | Visual Studio 解决方案入口，组织项目和平台配置。 |
| `Rasterizer.vcxproj` | 编译与链接设置：登记源码、C++ 标准、工具集和 OpenCV 依赖。 |
| `Rasterizer.vcxproj.filters` | Visual Studio 中的源文件与头文件分组。 |
| `.gitignore` | 排除本地 IDE 缓存、个人设置和编译产物。当前 `*.obj` 规则也会忽略 OBJ 模型文件。 |

## 实现流程

### 模型显示

```text
读取 OBJ → 生成多档简化网格
                    ↓
每帧更新相机 → 按距离选择 LOD
                    ↓
模型坐标 → 世界坐标 → 相机坐标 → 裁剪坐标
                    ↓
透视除法 → 屏幕坐标 → 三角形边线 → 像素缓冲 → OpenCV
```

采用矩阵乘列向量的约定：`projection * view * model * position`。相机朝自身 −Z 方向看，屏幕原点在左上角，X 向右、Y 向下。

### QEM 简化

1. 根据三角形平面建立误差矩阵，将它们累加到对应顶点。
2. 合并一条边两端的误差矩阵，比较端点、中点，以及能够稳定求出的最优位置。
3. 将候选放入按误差排序的优先队列。
4. 取出候选，检查版本是否过期，以及折叠是否满足局部几何和拓扑约束。
5. 执行折叠，更新存活状态、面索引、邻接表、误差矩阵和受影响顶点的版本号。
6. 重新生成受影响区域的候选；队列中的旧候选在取出时通过版本号淘汰。
7. 达到目标面数或候选耗尽后，移除无用顶点并重新编号，输出简化网格。

由于边界保护和折叠合法性限制，实际面数不一定能达到目标值；具体数量以控制台输出为准。
