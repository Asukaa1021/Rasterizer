# Rasterizer

一个从零编写的 C++ CPU 三角形光栅器，沿着 GAMES101 的学习思路，逐步理解三维顶点如何变成屏幕上的像素。向量、矩阵、相机变换、透视投影和三角形覆盖判断由项目自行实现，OpenCV 用于显示最终的黑白画面。

## 当前进度

- `Vec2`、`Vec3`、`Vec4`：向量加减、标量乘法、点乘，以及二维和三维叉乘；`Vec3` 支持归一化。
- `Mat4`：矩阵乘法、平移、旋转、缩放、`lookAt` 视图矩阵和透视投影矩阵。
- 顶点经过模型、视图、投影变换后，进行透视除法并映射到屏幕。
- 用屏幕包围盒缩小遍历范围，在像素中心通过叉乘判断三角形覆盖。
- 用一维数组保存二维画面的覆盖结果，再转换成 OpenCV 灰度图显示。

目前是学习中的基础版本：顶点虽然保存颜色，绘制结果暂时只有黑白覆盖；尚未实现视锥裁剪、深度测试、颜色插值、纹理和抗锯齿。先使用完全位于视野内、投影后 `w > 0` 的三角形验证。

## 从三维顶点到像素

```text
模型坐标
  → model：缩放、旋转、平移
世界坐标
  → view：转换到相机坐标系
相机坐标
  → projection：得到裁剪坐标
  → 透视除法：x、y、z 除以 w（当前绘制代码使用其中的 x、y）
  → 屏幕映射：转换成像素空间中的浮点坐标
  → 包围盒遍历与像素中心覆盖判断
  → pixels[y * width + x]
  → OpenCV 显示
```

完整流程中的三角形裁剪应位于透视除法之前，目前尚未实现。

坐标约定：矩阵乘列向量；相机朝自身的 −Z 方向看；可见区域在透视除法后对应 `[-1, 1]³`；屏幕原点位于左上角，X 向右、Y 向下。

## 构建与运行

当前开发环境为 Windows、支持 `.slnx` 和 v145 工具集的 Visual Studio，以及 OpenCV 4.13.0。工程采用 C++20。

1. 打开 `Rasterizer.slnx`，选择 **Debug / x64**。
2. 在项目属性中，根据自己的 OpenCV 安装位置设置：
   - **C/C++ → 常规 → 附加包含目录**：`<OpenCV>/build/include`
   - **链接器 → 常规 → 附加库目录**：`<OpenCV>/build/x64/vc16/lib`
   - **链接器 → 输入 → 附加依赖项**：`opencv_world4130d.lib`
3. 将 `opencv_world4130d.dll` 放到生成的可执行文件旁，或将其所在的 `bin` 目录加入运行时的 `PATH`。
4. 生成并运行。窗口显示黑底白色三角形，在图片窗口按键后程序结束。

仓库中的 Debug / x64 配置使用本机路径 `D:\OpenCV\opencv`，在其他电脑上需要按实际位置修改。Release / x64 尚未配置 OpenCV；若要使用，应单独配置路径并匹配不带 `d` 的库和 DLL。

## 自己动手修改

- 修改 `main.cpp` 中三个 `Vertex` 的位置，观察投影形状变化；输入的是三维模型坐标。
- 通过 `setModel` 应用平移、旋转或缩放。
- 修改 `lookAt` 的 `eye`、`target`、`up`，改变相机位置和朝向。
- 修改 `perspective` 的视野角、宽高比和近远裁剪面参数，观察透视变化。
